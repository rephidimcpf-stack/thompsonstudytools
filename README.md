# Thompson Study Companion — KJV + Telugu Bible

# ⚡ Quick start — just double-click

**Open `Thompson-Study-App.html`** — it's the whole app (every topic, concordance word, and both Bibles) packed into ONE file. Double-click it and everything works: navigation, verse popups in Telugu + KJV, notes, search, backup/restore.

> Even if you open it straight out of the ZIP without extracting, this single file still works fully.

## What's in this package

| File | Purpose |
|---|---|
| **Thompson-Study-App.html** | ✅ The complete app in one file — double-click, no install, works offline |
| **app/** folder | The same app as a PWA — for hosting online so it can be *installed* to a phone home screen with the icon, and cached for offline use |
| **HOW-TO-INSTALL.md** | Phone-install & hosting instructions (also below) |

**Key features**
- Every scripture reference is tappable → popup shows the verse in Telugu and KJV
- Chain/topic numbers (e.g. "3789") jump to the topic; character numbers (4286+) jump to studies
- Notes on any topic/character/word/verse, starred favourites, verse highlights
- Backup & restore to a single JSON file (choose the folder on PC)
- Search everything (press `/`)
- Light/dark theme, parchment-and-gold design

## Installing on your phone (home-screen icon)

The single file works great on a PC. For phone use with the app icon:

1. Put the **app/** folder on any free static host:
   - [Netlify Drop](https://app.netlify.com/drop) — drag the folder in, get a link in seconds, no account needed for temporary sites
   - [GitHub Pages](https://pages.github.com) — free and permanent
2. Open the link in **Chrome** (Android) or **Safari** (iPhone)
3. Install:
   - **Android**: menu ⋮ → *Add to Home screen*
   - **iPhone**: Share ⬆️ → *Add to Home Screen*

You get the custom Thompson icon, full-screen app, and it works offline.

> On a phone without hosting: copy `Thompson-Study-App.html` to the phone (WhatsApp/email/USB) and open it from a file manager — the whole app runs from that one file. (Notes depend on the browser allowing local storage.)
